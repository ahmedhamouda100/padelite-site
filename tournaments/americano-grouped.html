Bigger field, split into balanced groups by level and gender. Round-robin inside your group, then a Finals stage for the top qualifiers. The most competitive individual format we run.

How the draw works

When registration closes, Padelite runs a snake-draft: players are ranked by level, then distributed across groups so every group has a similar strength profile. Gender quotas per group keep mixed events truly mixed. You can see the algorithm's output before matches start — and organizers can move a player between groups if something looks off.

Group stage

Inside each group, the app generates a canonical Americano rotation. Every player plays with (and against) every other player exactly once — or as close as the group size allows. Matches use a fixed-point pool (typically 16 per match); ties are allowed.

Active court dispatcher

Organizers use the Active Queue to pick the next match by rest time — the app refuses matches that put a player on court twice in a row, and prevents double-booking courts. Live scoring updates the leaderboard in real time.

Finals stage

Top qualifiers from each group graduate to the Finals — a fresh Americano rotation among only the finalists. Podium finishers earn Padel Elite points (10 / 8 / 6 / 4 for 1st / 2nd / 3rd / 4th).

How to register

Get the Padelite app, find the Grouped Americano on your calendar, and tap Apply. Upload a payment receipt if the event requires one.
